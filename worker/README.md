# Worker — VM Management Daemon

It has 3 main parts.

## Server
A rpc server listening for commands to apply, it can create, delete, list and so on.

## Registry
The strucutre holding the state with the vms running. Split into two faces, the write and the read face.
The separation is to avoid locking. However it has an sqlite db so the reader face could have some 'quick' write capabilities?

## Supervisor
Holds the writting part of registry. It receives commands from a channel comming from the server part. Once a command comes in it executes it

## Factory
A structure that is dependand of the backend used, currently it's cloud hypervisor.
It creates the vms (in this case it spawns a process and creates a client to communicate with it)

## Run it

My main nix config has the procurator flake imported as a module
```nix
nixosConfigurations = {
    server = nixpkgs.lib.nixosSystem {
    system = "x86_64-linux";
    modules = [
        ./hosts/server/configuration.nix
        inputs.procurator.nixosModules.x86_64-linux.procurator
    ];
    };
}
```
this allows me to declare the service `vmm` which configures the bridge and other stuff related to virtual networking
```nix
{
  services.procurator = {
    vmm = {
      enable = true;
      # This is my wifi card, you might have something different
      externalInterface = "wlp98s0";
    };
  };
}
```

Once all the virtual networking set up, two things are needed. First the worker has to run.
```bash
nix run .#worker
```

Then you need the artifacts for the VM. There is a cli to test the worker and the creation of VMs. By default it uses the artifacts generated by the below command. I don't remember what it really takes, it has been AI generated, but this works on my machine (with nix it should work in any machine)
```bash
nix build ./nix/examples/python-workload#artifacts
```

Once the worker running and the artifacts created. Run the create command of the test cli. You don't need any arg as it uses the defaults pointing to the ones previously generated.
```bash
nix run .#worker-test -- create
```
This command takes like 3 seconds and returns the ID of the VM. To get the IP run the command below.
NOTE: We could try to make it faster, but everything is mostly sequential. Creating the tap, attaching it, getting an unused IP, spawing a cloud-hypervisor process, checking that the socket is ready so we can create the VM. All needs to be sequentail-ish, the socket and process spawing is probably the slowest part, we could just save the settings in the db and do the work in background tho

To get the IP of all the VMs run:
```bash
nix run .#worker-test -- list
```
And ssh into the vm if you want
