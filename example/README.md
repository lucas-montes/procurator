# Local cache example

This example shows a minimal Rust project that you can build locally, push to the
cache, and then reuse from that cache later.

## 1) Start the cache

From the repository root:

```bash
cargo run -p cache -- --config ./cache/example.toml
```

## 2) Build the project

```bash
cd example
cargo build
```

Or with Nix:

```bash
nix build .
```

## 3) Push the built result to the cache

Use the local cache as the substituter:

```bash
nix copy --to http://127.0.0.1:8081 ./result
```

If you have a real signing key configured in the cache, the cache will also sign the
uploaded narinfo entries.

## 4) Pull it back from the cache later

```bash
nix copy --from http://127.0.0.1:8081 ./result
```

## 5) Reuse the cache in the flake

The flake includes a `nixConfig` block so the project automatically uses the local cache:

```nix
nixConfig = {
  substituters = [ "http://127.0.0.1:8081" ];
  trusted-public-keys = [ "cache.local-1:REPLACE_WITH_YOUR_PUBLIC_KEY_BASE64" ];
  accept-flake-config = true;
};
```

If you prefer the non-flake form, the equivalent is:

```nix
nix.settings.substituters = [ "http://127.0.0.1:8081" ];
nix.settings.trusted-public-keys = [ "cache.local-1:REPLACE_WITH_YOUR_PUBLIC_KEY_BASE64" ];
```

## Notes

- Replace the placeholder public key with the one generated by the cache.
- This is just a minimal example; the important part is the build -> push -> reuse pattern.
